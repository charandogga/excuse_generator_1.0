#  AI Excuse Generator

An interactive web app built using HTML, CSS, and JavaScript that generates contextual excuses, apology messages, and proof-style documents with a clean responsive UI.

##  Features

* Dynamic excuse generation
* Multiple categories and urgency levels
* AI-style believability scoring
* Apology message generation
* Proof document templates
* History tracking system

##  Technologies Used

* HTML5
* CSS3
* JavaScript
